The terminal is one of the most frequently used tools in any programmer's arsenal, yet the terminal can also have a steep learning curve. This is also compounded if you use a Mac running Apple Silicon. There are 10 years of helpful resources to learn how to do things on Intel Macs, but Apple Silicon is relatively recent. 

This blog summarizes what ZSH is and how to add a path to ~/.zshrc. First, I will briefly summarize some of the terminology.

## What is Bash?

Bash (Bourne Again Shell) is a command line interpreter for Unix users to communicate directly with the computer through the command line.

## What is ZSH?

ZSH (Z shell) is an extended version of Bash. There are a number of differences between the two, but this is outside the scope of this blog. 

## What is /.zshrc?

`.zshrc` is a ZSH config file used for interactive shells. It includes behavior and appearance settings for interactive shells. 

## Adding a path to /.zshrc

There is some debate about whether to add path to `~/.zshrc` or `~/.zprofile`. I have been adding my paths to `~/.zshrc`, but it is worth reading through this post about [ZSH configuration files](https://www.baeldung.com/linux/zsh-configuration-files) to decide for yourself. 

In terminal, use vim or another text editor to open your `~/.zshrc` file. 

```bash
vim ~/.zshrc
```

Next, if we want to add ./vendor/bin to the path, we will add the below to your `~/.zshrc` file

```bash
export PATH="./vendor/bin:$PATH"
```

In short, this adds `./vendor/bin` and appends what is currently in `$PATH` afterward so that we don't overwrite our previous exports.

If you're using vim, you can type `:wq` and press enter to write to the file and quit.

Finally, run the below source command to reload your `~/.zshrc` file so that the new path is available in the terminal session. 

```bash
source /.zshrc
```

After this, you should be able to run whatever tool you added to path by calling the tool command.
